Языки программирования

Меня зовут Папета Сергей, сегодня я хочу поговорить о 3 китах фронтенда, а именно о HTML, CSS, JavaScript.

В современном мире интернет стал неотъемлемой частью жизни: мы используем сайты для общения, поиска информации, учёбы, работы и развлечений. Умение создавать веб-ресурсы -- это ключевой навык цифровой эпохи. Он полезен не только будущим разработчикам, но и представителям многих профессий: копирайтерам, контент-менеджерам, SEO-специалистам. Знание основ веб-разработки позволяет не просто пользоваться готовыми платформами, но и реализовывать собственные идеи: создавать лендинги, персональные визитки, учебные проекты. Кроме того, процесс создания сайта развивает алгоритмическое мышление и умение структурировать информацию.

HTML

HTML (HyperText Markup Language) -- это язык гипертекстовой разметки, который служит фундаментом для создания веб-страниц. Он задаёт их структуру, определяя, где будут заголовки, абзацы, изображения, ссылки и другие элементы. Без HTML браузер не смог бы отобразить содержимое сайта.

История создания

HTML разработал британский учёный Тим Бернерс-Ли примерно в 1986–1991 годах в Европейском центре ядерных исследований (CERN) в Женеве. Изначально язык создавался как средство для обмена научной и технической документацией, удобное для людей, не являющихся специалистами в вёрстке. Первая версия включала всего 18 тегов и была упрощённой версией более сложного языка SGML.

Ключевые особенности

Не является языком программирования. HTML только структурирует контент и определяет его смысл, но не содержит логических операторов, циклов или переменных. Всё, что связано с интерактивностью и динамикой (анимация, валидация форм, сложные вычисления), требует интеграции с другими технологиями, например, JavaScript.

Основа для других технологий. HTML задаёт структуру страницы, CSS отвечает за её визуальное оформление (цвета, шрифты, расположение), а JavaScript добавляет интерактивность.

Семантическая разметка. Современные версии HTML (начиная с HTML5) включают теги, которые чётко описывают назначение контента: header, main, article, footer, nav. Это улучшает доступность для людей с ограниченными возможностями и помогает поисковым системам лучше понимать страницу.

Как устроен HTML

Теги -- это основные строительные блоки HTML. Они выглядят как <имя> и указывают браузеру, как отображать содержимое. Большинство тегов парные (открывающий и закрывающий), но есть и одиночные (самозакрывающиеся), например, <br> или <img>.

Атрибуты -- это дополнительные характеристики, которые задают свойства элемента. Например, у тега <img> есть атрибут src (указывает путь к изображению) и alt (альтернативный текст, который отображается, если картинка не загрузится).

Базовая структура HTML-документа включает несколько обязательных элементов:

<!DOCTYPE html> -- объявление типа документа, которое указывает браузеру, что это документ HTML5.

<html> -- корневой элемент, внутри которого заключены все остальные элементы страницы.

<head> -- раздел с метаданными (заголовок страницы, кодировка, ссылки на стили CSS, метатеги для SEO).

<body> -- тело документа, где размещается весь видимый пользователю контент: текст, изображения, ссылки, таблицы, формы.

Основные возможности

С помощью HTML можно: создавать структурированные документы с заголовками, абзацами, списками, таблицами; встраивать мультимедийный контент: изображения, видео, аудио; добавлять ссылки для навигации между страницами; создавать интерактивные элементы, например, формы для ввода данных.

JavaScript

JavaScript -- это язык программирования, который в первую очередь делает веб-страницы интерактивными. С его помощью кнопки реагируют на клики, формы проверяют данные, появляется анимация, а контент подгружается динамически -- без полной перезагрузки страницы.

История появления

Язык создали в 1995 году в компании Netscape. Сотрудник Брендан Эйх разработал прототип всего за 10 дней. Сначала язык назывался Mocha, потом LiveScript, а в декабре 1995 года его переименовали в JavaScript. Чтобы стандартизировать язык и устранить несовместимости между браузерами, Netscape передала его спецификацию в организацию ECMA. Так появился стандарт ECMAScript (первый релиз -- 1997 год). С тех пор развитие языка идёт в рамках этого стандарта.

Ключевые особенности

Интерпретируемый. Код выполняется построчно сразу, без отдельной фазы компиляции. Интерпретатор встроен во все современные браузеры.

Мультипарадигменный. Поддерживает разные стили программирования: объектно-ориентированный, императивный и функциональный.

Динамическая типизация. Тип переменной определяется в момент присвоения значения и может меняться в процессе работы программы.

Автоматическое управление памятью (работает сборщик мусора).

Прототипное наследование. В отличие от классового наследования в некоторых других языках, в JavaScript объекты наследуют свойства и методы непосредственно от других объектов-прототипов.

Однопоточность. Сам язык выполняет код в одном потоке, но асинхронные механизмы (цикл событий -- Event Loop) позволяют не «замораживать» интерфейс при длительных операциях (например, загрузке данных).

Где применяется?

Фронтенд-разработка. Главная сфера: интерактивные элементы сайтов, формы, анимации, обработка пользовательских действий.

Бэкенд. С появлением платформы Node.js JavaScript вышел за пределы браузера. Теперь на нём пишут серверную часть, API, микросервисы. Также появились современные среды вроде Bun и Deno.

Мобильные приложения. С фреймворками React Native, Ionic можно создавать кроссплатформенные приложения.

Десктопные программы. Например, с помощью фреймворка Electron.

Браузерные расширения. Скрипты на JS могут расширять функционал браузера (блокировать рекламу, менять дизайн).

CSS

CSS (Cascading Style Sheets -- «каскадные таблицы стилей») -- это язык, который отвечает за внешний вид веб-страниц: цвета, шрифты, отступы, расположение блоков и многое другое.

Немного истории

Концепцию CSS предложил Хокон Виум Ли в 1994 году, а первую спецификацию выпустил консорциум W3C в 1996-м. Со временем язык сильно развивался: появились модули (CSS2, затем CSS3), а в последние годы особенно активно развиваются инструменты для сложной вёрстки -- Flexbox и Grid. Также появились CSS-переменные и функции (calc() и другие).

Что он делает

Главная идея CSS -- разделить структуру контента и его визуальное оформление. HTML задаёт каркас (заголовки, абзацы, списки), а CSS описывает, как этот контент должен выглядеть. Это даёт несколько плюсов: легко менять дизайн, не трогая структуру HTML; повторно использовать стили на разных страницах; улучшать доступность; создавать адаптивные дизайны с помощью медиа-запросов.

Как это устроено

Основа CSS -- правила. Каждое правило состоит из трёх частей: селектор (указывает, к каким HTML-элементам применять стили), свойство (что именно меняем -- цвет, размер шрифта, фон) и значение (конкретное значение для свойства).

Ключевые принципы

Каскадность. Если к одному элементу применимо несколько правил, порядок их следования в коде имеет значение. Наследование. Некоторые свойства передаются от родительского элемента к дочерним. Специфичность. Механизм, который решает конфликты: у разных селекторов разный «вес», и правило с более высоким весом имеет приоритет.

Не является языком программирования. HTML только структурирует контент и определяет его смысл, но не содержит логических операторов, циклов или переменных. Всё, что связано с интерактивностью и динамикой (анимация, валидация форм, сложные вычисления), требует интеграции с другими технологиями, например, JavaScript.

Основа для других технологий. HTML задаёт структуру страницы, CSS отвечает за её визуальное оформление (цвета, шрифты, расположение), а JavaScript добавляет интерактивность.

Семантическая разметка. Современные версии HTML (начиная с HTML5) включают теги, которые чётко описывают назначение контента: header, main, article, footer, nav. Это улучшает доступность для людей с ограниченными возможностями и помогает поисковым системам лучше понимать страницу.

Как устроен HTML

Теги -- это основные строительные блоки HTML. Они выглядят как <имя> и указывают браузеру, как отображать содержимое. Большинство тегов парные (открывающий и закрывающий), но есть и одиночные (самозакрывающиеся), например, <br> или <img>.

Атрибуты -- это дополнительные характеристики, которые задают свойства элемента. Например, у тега <img> есть атрибут src (указывает путь к изображению) и alt (альтернативный текст, который отображается, если картинка не загрузится).

Базовая структура HTML-документа включает несколько обязательных элементов:

<!DOCTYPE html> -- объявление типа документа, которое указывает браузеру, что это документ HTML5.

<html> -- корневой элемент, внутри которого заключены все остальные элементы страницы.

<head> -- раздел с метаданными (заголовок страницы, кодировка, ссылки на стили CSS, метатеги для SEO).

<body> -- тело документа, где размещается весь видимый пользователю контент: текст, изображения, ссылки, таблицы, формы.

Основные возможности

С помощью HTML можно: создавать структурированные документы с заголовками, абзацами, списками, таблицами; встраивать мультимедийный контент: изображения, видео, аудио; добавлять ссылки для навигации между страницами; создавать интерактивные элементы, например, формы для ввода данных.

JavaScript

JavaScript -- это язык программирования, который в первую очередь делает веб-страницы интерактивными. С его помощью кнопки реагируют на клики, формы проверяют данные, появляется анимация, а контент подгружается динамически -- без полной перезагрузки страницы.

История появления

Язык создали в 1995 году в компании Netscape. Сотрудник Брендан Эйх разработал прототип всего за 10 дней. Сначала язык назывался Mocha, потом LiveScript, а в декабре 1995 года его переименовали в JavaScript. Чтобы стандартизировать язык и устранить несовместимости между браузерами, Netscape передала его спецификацию в организацию ECMA. Так появился стандарт ECMAScript (первый релиз -- 1997 год). С тех пор развитие языка идёт в рамках этого стандарта.

Ключевые особенности

Интерпретируемый. Код выполняется построчно сразу, без отдельной фазы компиляции. Интерпретатор встроен во все современные браузеры.

Мультипарадигменный. Поддерживает разные стили программирования: объектно-ориентированный, императивный и функциональный.

Динамическая типизация. Тип переменной определяется в момент присвоения значения и может меняться в процессе работы программы.

Автоматическое управление памятью (работает сборщик мусора).

Прототипное наследование. В отличие от классового наследования в некоторых других языках, в JavaScript объекты наследуют свойства и методы непосредственно от других объектов-прототипов.

Однопоточность. Сам язык выполняет код в одном потоке, но асинхронные механизмы (цикл событий -- Event Loop) позволяют не «замораживать» интерфейс при длительных операциях (например, загрузке данных).

Где применяется?

Фронтенд-разработка. Главная сфера: интерактивные элементы сайтов, формы, анимации, обработка пользовательских действий.

Бэкенд. С появлением платформы Node.js JavaScript вышел за пределы браузера. Теперь на нём пишут серверную часть, API, микросервисы. Также появились современные среды вроде Bun и Deno.

Мобильные приложения. С фреймворками React Native, Ionic можно создавать кроссплатформенные приложения.

Десктопные программы. Например, с помощью фреймворка Electron.

Браузерные расширения. Скрипты на JS могут расширять функционал браузера (блокировать рекламу, менять дизайн).

CSS

CSS (Cascading Style Sheets -- «каскадные таблицы стилей») -- это язык, который отвечает за внешний вид веб-страниц: цвета, шрифты, отступы, расположение блоков и многое другое.

Немного истории

Концепцию CSS предложил Хокон Виум Ли в 1994 году, а первую спецификацию выпустил консорциум W3C в 1996-м. Со временем язык сильно развивался: появились модули (CSS2, затем CSS3), а в последние годы особенно активно развиваются инструменты для сложной вёрстки -- Flexbox и Grid. Также появились CSS-переменные и функции (calc() и другие).

Что он делает

Главная идея CSS -- разделить структуру контента и его визуальное оформление. HTML задаёт каркас (заголовки, абзацы, списки), а CSS описывает, как этот контент должен выглядеть. Это даёт несколько плюсов: легко менять дизайн, не трогая структуру HTML; повторно использовать стили на разных страницах; улучшать доступность; создавать адаптивные дизайны с помощью медиа-запросов.

Как это устроено

Основа CSS -- правила. Каждое правило состоит из трёх частей: селектор (указывает, к каким HTML-элементам применять стили), свойство (что именно меняем -- цвет, размер шрифта, фон) и значение (конкретное значение для свойства).

Ключевые принципы

Каскадность. Если к одному элементу применимо несколько правил, порядок их следования в коде имеет значение. Наследование. Некоторые свойства передаются от родительского элемента к дочерним. Специфичность. Механизм, который решает конфликты: у разных селекторов разный «вес», и правило с более высоким весом имеет приоритет.

<head> -- раздел с метаданными (заголовок страницы, кодировка, ссылки на стили CSS, метатеги для SEO).

<body> -- тело документа, где размещается весь видимый пользователю контент: текст, изображения, ссылки, таблицы, формы.

Основные возможности

С помощью HTML можно: создавать структурированные документы с заголовками, абзацами, списками, таблицами; встраивать мультимедийный контент: изображения, видео, аудио; добавлять ссылки для навигации между страницами; создавать интерактивные элементы, например, формы для ввода данных.

JavaScript

JavaScript -- это язык программирования, который в первую очередь делает веб-страницы интерактивными. С его помощью кнопки реагируют на клики, формы проверяют данные, появляется анимация, а контент подгружается динамически -- без полной перезагрузки страницы.

История появления

Язык создали в 1995 году в компании Netscape. Сотрудник Брендан Эйх разработал прототип всего за 10 дней. Сначала язык назывался Mocha, потом LiveScript, а в декабре 1995 года его переименовали в JavaScript. Чтобы стандартизировать язык и устранить несовместимости между браузерами, Netscape передала его спецификацию в организацию ECMA. Так появился стандарт ECMAScript (первый релиз -- 1997 год). С тех пор развитие языка идёт в рамках этого стандарта.

Ключевые особенности

Интерпретируемый. Код выполняется построчно сразу, без отдельной фазы компиляции. Интерпретатор встроен во все современные браузеры.

Мультипарадигменный. Поддерживает разные стили программирования: объектно-ориентированный, императивный и функциональный.

Динамическая типизация. Тип переменной определяется в момент присвоения значения и может меняться в процессе работы программы.

Автоматическое управление памятью (работает сборщик мусора).

Прототипное наследование. В отличие от классового наследования в некоторых других языках, в JavaScript объекты наследуют свойства и методы непосредственно от других объектов-прототипов.

Однопоточность. Сам язык выполняет код в одном потоке, но асинхронные механизмы (цикл событий -- Event Loop) позволяют не «замораживать» интерфейс при длительных операциях (например, загрузке данных).

Где применяется?

Фронтенд-разработка. Главная сфера: интерактивные элементы сайтов, формы, анимации, обработка пользовательских действий.

Бэкенд. С появлением платформы Node.js JavaScript вышел за пределы браузера. Теперь на нём пишут серверную часть, API, микросервисы. Также появились современные среды вроде Bun и Deno.

Мобильные приложения. С фреймворками React Native, Ionic можно создавать кроссплатформенные приложения.

Десктопные программы. Например, с помощью фреймворка Electron.

Браузерные расширения. Скрипты на JS могут расширять функционал браузера (блокировать рекламу, менять дизайн).

CSS

CSS (Cascading Style Sheets -- «каскадные таблицы стилей») -- это язык, который отвечает за внешний вид веб-страниц: цвета, шрифты, отступы, расположение блоков и многое другое.

Немного истории

Концепцию CSS предложил Хокон Виум Ли в 1994 году, а первую спецификацию выпустил консорциум W3C в 1996-м. Со временем язык сильно развивался: появились модули (CSS2, затем CSS3), а в последние годы особенно активно развиваются инструменты для сложной вёрстки -- Flexbox и Grid. Также появились CSS-переменные и функции (calc() и другие).

Что он делает

Главная идея CSS -- разделить структуру контента и его визуальное оформление. HTML задаёт каркас (заголовки, абзацы, списки), а CSS описывает, как этот контент должен выглядеть. Это даёт несколько плюсов: легко менять дизайн, не трогая структуру HTML; повторно использовать стили на разных страницах; улучшать доступность; создавать адаптивные дизайны с помощью медиа-запросов.

Как это устроено

Основа CSS -- правила. Каждое правило состоит из трёх частей: селектор (указывает, к каким HTML-элементам применять стили), свойство (что именно меняем -- цвет, размер шрифта, фон) и значение (конкретное значение для свойства).

Ключевые принципы

Каскадность. Если к одному элементу применимо несколько правил, порядок их следования в коде имеет значение. Наследование. Некоторые свойства передаются от родительского элемента к дочерним. Специфичность. Механизм, который решает конфликты: у разных селекторов разный «вес», и правило с более высоким весом имеет приоритет.

HTML

HTML (HyperText Markup Language) -- это язык гипертекстовой разметки, который служит фундаментом для создания веб-страниц. Он задаёт их структуру, определяя, где будут заголовки, абзацы, изображения, ссылки и другие элементы. Без HTML браузер не смог бы отобразить содержимое сайта.

История создания

HTML разработал британский учёный Тим Бернерс-Ли примерно в 1986–1991 годах в Европейском центре ядерных исследований (CERN) в Женеве. Изначально язык создавался как средство для обмена научной и технической документацией, удобное для людей, не являющихся специалистами в вёрстке. Первая версия включала всего 18 тегов и была упрощённой версией более сложного языка SGML.

Ключевые особенности

Не является языком программирования. HTML только структурирует контент и определяет его смысл, но не содержит логических операторов, циклов или переменных. Всё, что связано с интерактивностью и динамикой (анимация, валидация форм, сложные вычисления), требует интеграции с другими технологиями, например, JavaScript.

Основа для других технологий. HTML задаёт структуру страницы, CSS отвечает за её визуальное оформление (цвета, шрифты, расположение), а JavaScript добавляет интерактивность.

Семантическая разметка. Современные версии HTML (начиная с HTML5) включают теги, которые чётко описывают назначение контента: header, main, article, footer, nav. Это улучшает доступность для людей с ограниченными возможностями и помогает поисковым системам лучше понимать страницу.

Как устроен HTML

Теги -- это основные строительные блоки HTML. Они выглядят как <имя> и указывают браузеру, как отображать содержимое. Большинство тегов парные (открывающий и закрывающий), но есть и одиночные (самозакрывающиеся), например, <br> или <img>.

Атрибуты -- это дополнительные характеристики, которые задают свойства элемента. Например, у тега <img> есть атрибут src (указывает путь к изображению) и alt (альтернативный текст, который отображается, если картинка не загрузится).

Базовая структура HTML-документа включает несколько обязательных элементов:

<!DOCTYPE html> -- объявление типа документа, которое указывает браузеру, что это документ HTML5.

<html> -- корневой элемент, внутри которого заключены все остальные элементы страницы.

<head> -- раздел с метаданными (заголовок страницы, кодировка, ссылки на стили CSS, метатеги для SEO).

<body> -- тело документа, где размещается весь видимый пользователю контент: текст, изображения, ссылки, таблицы, формы.

Основные возможности

С помощью HTML можно: создавать структурированные документы с заголовками, абзацами, списками, таблицами; встраивать мультимедийный контент: изображения, видео, аудио; добавлять ссылки для навигации между страницами; создавать интерактивные элементы, например, формы для ввода данных.
